# Seattle-extension Project

This project analyzes the robustness of Seattle's transportation and power networks under targeted node removal attacks. It uses network analysis techniques, including centrality measures and Louvain community detection, to understand how these critical infrastructures respond to failures. The pipeline generates both quantitative metrics and geographical visualizations of the attack scenarios.

## Project Structure

The core logic of the analysis is contained within the `scripts/` directory, while input data, intermediate outputs, and final figures are stored in their respective folders.

```
.
├── data/                    # Input data for transportation and power networks
├── logs/                    # Execution logs (if any, not explicitly generated by scripts)
├── output/                  # All generated output files
│   ├── figures/             # Image outputs (PNGs)
│   │   ├── combined/        # Figures comparing both networks
│   │   ├── power/           # Figures specific to the power network
│   │   └── transport/       # Figures specific to the transportation network
│   ├── power/               # Data outputs specific to the power network (CSVs, PKLs)
│   └── transport/           # Data outputs specific to the transportation network (CSVs, PKLs)
└── scripts/                 # Python scripts implementing the analysis pipeline
    ├── run_all.py           # Orchestrates the execution of all other scripts
    ├── script_01_build_graph.py   # Builds graphs, computes centralities, and finds articulation points
    ├── script_02_percolation.py   # Performs percolation analysis, community detection, and path length analysis
    ├── script_03_comparison.py    # Generates comparative plots and summary statistics
    ├── script_04_geodviz.py       # Creates geographical visualizations of community structure
    ├── script_05_build_multilayer.py # Creates a multilayer interdependent network
    ├── script_06_multilayer_viz.py# Visualizes the multilayer graph geographically
    └── script_07_multilayer_community.py # Performs multilayer community detection via dual identity
```

## Workflow Overview

The analysis follows a seven-step pipeline, orchestrated by `run_all.py`:

1.  **Graph Construction and Centrality Calculation (`script_01_build_graph.py`)**:
    *   Reads raw node and edge data for both transportation and power networks.
    *   Constructs NetworkX graphs and extracts the Largest Connected Component (LCC).
    *   Calculates node betweenness centrality (BC) and degree centrality (DC).
    *   Identifies network articulation points (cut vertices).
    *   **Outputs**: `lcc_graph.pkl`, `removal_order_bc.csv`, `removal_order_dc.csv`, `articulation_points.csv` for each network.

2.  **Percolation Analysis and Community Detection (`script_02_percolation.py`)**:
    *   Loads the LCC graphs and centrality-based removal orders.
    *   **Tipping Point Scan**: Simulates incremental node removals to find the point where each network fractures, performing Louvain community detection at the tipping point.
    *   **Full-Attack Snapshot**: Simulates a targeted attack by removing the top 10 most central nodes, then analyzes the resulting network's connected components and Louvain communities.
    *   **Louvain Stability Check**: Assesses the consistency of Louvain community detection results by running it multiple times with different random seeds.
    *   **Average Path Length Analysis**: Estimates changes in average shortest-path length after a BC-based attack.
    *   **Outputs**: `tipping_points.csv`, `community_assignments_{bc/dc}_tipping.pkl`, `post_attack_{bc/dc}.csv`, `community_assignments_{bc/dc}_full.pkl`, `louvain_stability.csv`, `path_length_analysis.csv`, and `modularity_comparison.csv` for each network.

3.  **Comparative Plotting and Summary (`script_03_comparison.py`)**:
    *   Loads all quantitative results generated by `script_02`.
    *   Generates a suite of `matplotlib` plots to visually compare the impact of BC and DC attacks on both networks. These include:
        *   Tipping point comparisons.
        *   Community size distributions after attacks.
        *   Summaries of connected components, non-trivial communities, and modularity.
    *   Produces both network-specific and combined (transport vs. power) plots.
    *   Prints a summary table to the console.
    *   **Outputs**: Various `.png` image files stored in `output/figures/`.

4.  **Geographical Visualization (`script_04_geodviz.py`)**:
    *   Loads LCC graphs, community assignments, and removal orders.
    *   Transforms all geographical coordinates to `WGS84` for consistent plotting.
    *   Generates scatter plots of network nodes, colored by their Louvain community membership, and highlights the nodes removed during attacks.
    *   Creates detailed maps for both individual networks and combined side-by-side views.
    *   **Outputs**: `map_*.png` image files stored in `output/figures/`.

5.  **Multilayer Network Construction (`script_05_build_multilayer.py`)**:
    *   Creates a multilayer interdependent network by coupling the transportation and power networks.
    *   Links nodes between the two layers using a KD-Tree nearest neighbor search.
    *   **Outputs**: `multilayer_graph.pkl`, `interlayer_edges.csv`, and linked BC nodes data in `output/multilayer/`.

6.  **Multilayer Network Visualization (`script_06_multilayer_viz.py`)**:
    *   Visualizes the multilayer graph geographically, highlighting linked Betweenness Centrality (BC) nodes.
    *   Generates a full city-scale map.
    *   **Outputs**: `multilayer_full_map.png` image file stored in `output/figures/multilayer/`.

7.  **Multilayer Community Detection (`script_07_multilayer_community.py`)**:
    *   Analyzes "dual identity" pairings between Road and Power communities.
    *   Identifies frequent pairings for both baseline and linked BC attack scenarios.
    *   **Outputs**: `pair_frequencies_*.csv`, `multilayer_assignments_*.csv`, and geographical maps in `output/figures/multilayer/`.

## How to Run

To run the entire analysis pipeline, navigate to the `Seattle-extension/` directory and execute the `run_all.py` script:

```bash
python scripts/run_all.py
```

This will sequentially execute all analysis steps, generating data files and figures in the `output/` directory.

### Individual Script Execution

You can also run individual scripts if needed, but ensure that their dependencies (outputs from preceding scripts) are already generated.

```bash
python scripts/script_01_build_graph.py
python scripts/script_02_percolation.py
python scripts/script_03_comparison.py
python scripts/script_04_geodviz.py
python scripts/script_05_build_multilayer.py
python scripts/script_06_multilayer_viz.py
python scripts/script_07_multilayer_community.py
```

## Dependencies

The project relies on standard Python libraries for data manipulation, network analysis, and plotting. Ensure you have the following installed:

*   `pandas`
*   `networkx`
*   `matplotlib`
*   `numpy`
*   `pyproj`
*   `python-louvain` (likely installed as part of networkx community algorithms)

You can install these using pip:

```bash
pip install pandas networkx matplotlib numpy pyproj python-louvain
```
